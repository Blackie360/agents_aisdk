# Tech Community Manager AI - Sample Prompts

This document contains sample prompts to help you get the most out of your Tech Community Manager AI assistant. The agent has continuous access to Google Search to provide you with the latest information and best practices.

## Community Strategy & Growth

### Building Community Programs
```
Help me design an ambassador program for our developer community. Include:
- Selection criteria for ambassadors
- Benefits and perks structure
- Responsibilities and expectations
- Onboarding process
- Success metrics
```

### Community Health Metrics
```
What KPIs should I track to measure the health and engagement of our tech community?
Include both quantitative and qualitative metrics.
```

### Growth Strategies
```
Our developer community has 500 active members. Create a 3-month growth plan to reach 2000 members.
Include specific tactics, channels, and estimated resources needed.
```

### Community Guidelines
```
Draft a code of conduct for our online developer community that covers:
- Expected behavior
- Consequences for violations
- Reporting process
- Moderation guidelines
```

## Event Planning & Management

### Virtual Hackathon
```
Create a comprehensive plan for a 48-hour virtual hackathon including:
- Pre-event checklist
- Tools and platforms needed
- Judging criteria
- Prize structure ideas
- Post-event follow-up
```

### Monthly Meetup Series
```
Generate 6 months of meetup topics for a JavaScript developer community.
Include format ideas (talks, workshops, panels) and potential speaker profiles.
```

### Conference Planning
```
I'm organizing a developer conference for 300 attendees. Create a timeline
starting 6 months before the event with all major milestones and tasks.
```

### Speaker Outreach
```
Draft an email template for inviting speakers to our tech conference.
Include what information to provide and how to make it compelling.
```

```
3. Success story from beta testing
```

### Newsletter Content
```
Draft a monthly community newsletter with these sections:
- Opening message from community lead

- Technical tip of the month

```

### Blog Posts
```
Write a blog post titled "5 Ways to Get More Value from Our Developer Community"

```

## Developer Relations

### Advocacy Programs
```
Design a developer advocate program for our API platform. Include:
- Program goals and objectives
- Advocate activities and responsibilities
- Content creation guidelines
- Compensation/incentive structure
- Success metrics
```

### Open Source Engagement
```
Create a strategy for engaging with open source communities related to our product.
Include contribution guidelines, sponsorship opportunities, and maintainer relations.
```

### Feedback Loop
```

Include tools, processes, and team responsibilities.
```


## Research & Insights

### Industry Trends
```
What are the top 5 trends in developer communities and DevRel for 2025?
Include specific examples and how we can apply them.
```

### Competitive Analysis
```
Research how [Company X] manages their developer community.
What can we learn from their approach? What are they doing well?
```

### Tool Evaluation
```
Compare Discord, Slack, and dedicated community platforms (like Circle or Discourse)
for a developer community of 1000+ members. Include pros, cons, and cost analysis.
```

### Conference Research
```
Find all major developer conferences happening in Q2 2025 focused on
[your technology stack]. Include dates, locations, CFP deadlines, and expected attendance.
```

### Best Practices Research
```
What are the best practices for onboarding new community members in tech communities?
Find recent articles, case studies, and data-backed recommendations.
```

## Analytics & Reporting

### Monthly Report
```
Create a template for a monthly community metrics report including:
- Growth metrics
- Engagement metrics

```

### Success Stories

### ROI Analysis
```
How can I demonstrate the ROI of our community efforts to leadership?

```

## Tips for Better Results

1. **Be Specific**: The more context you provide, the better the responses
2. **Use Follow-ups**: Ask clarifying questions or request different approaches
3. **Request Examples**: Ask for real-world examples or case studies
4. **Ask for Research**: The agent can search the web for latest information
5. **Iterate**: Refine the output by providing feedback on what to adjust

## Example Multi-Turn Conversation

```
You: "Help me plan a developer meetup for our API community"

Agent: [Provides initial plan]

You: "Can you make it more interactive? We want hands-on activities"

Agent: [Adjusts plan with workshops and coding challenges]

You: "Find examples of successful API developer meetups from other companies"

Agent: [Searches web and provides relevant examples]

You: "Create a budget template for this meetup"

Agent: [Provides detailed budget breakdown]
```

Remember: The agent has continuous Google Search access, so don't hesitate to ask for the latest information, current trends, or recent examples!
